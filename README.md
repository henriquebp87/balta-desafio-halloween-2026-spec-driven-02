### Sobre este desafio
Neste desafio o objetivo é criar um encurtador de URLs completo utilizando os conceitos de Spec-Driven Development

#### O que foi implementado
- Uma API com 3 endpoints:
  - Um endpoint para criar encurtador: POST /
  - Um endpoint para redirecionar encurtador: GET /{code}
  - Um endpoint para acessar estatísticas de cada encurtador: GET /{code}/stats

Neste processo eu aprendi:
* Como implementar Spec-Driven Development de ponta a ponta
* Como gerar prompts para implementação de funcionalidades, respeitando a constituição, especificação e plano do projeto.
